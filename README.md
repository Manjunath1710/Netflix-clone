# Netflix Clone

A Netflix India landing page clone built using HTML and CSS.

## 🚀 About the Project

This project is a frontend recreation of the Netflix India landing page. I built it to practice and improve my HTML and CSS skills, including layout design, positioning, backgrounds, navigation bars.

## 🛠️ Technologies Used

- HTML5
- CSS3

## ✨ Features

- Netflix-style navigation bar
- Hero section with background image
- Email input and CTA button
- Trending section
- Frequently Asked Questions section
- Footer with useful links
